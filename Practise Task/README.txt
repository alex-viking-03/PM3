Менеджер студентов

Назначение программы

«Менеджер студентов» — настольное приложение для хранения и управления информацией о студентах, учебных группах, предметах и оценках. Программа позволяет вести простой электронный учёт успеваемости и сохраняет данные между запусками.

Используемые технологии

Python 3;

CustomTkinter — графический интерфейс;

SQLite — локальная база данных;

встроенный модуль sqlite3 — выполнение запросов к базе данных;

модуль tkinter.messagebox — диалоговые окна и уведомления.

Как запустить программу

Установить Python версии 3.10 или новее.

Скачать или клонировать проект.

Открыть терминал в папке проекта.

Установить библиотеку CustomTkinter:

pip install customtkinter

Запустить главный файл:

python main.py

При первом запуске программа автоматически создаст файл базы данных students.db и необходимые таблицы.

Основные функции

Работа со студентами

просмотр списка студентов;

добавление нового студента;

редактирование ФИО и группы студента;

удаление студента;

поиск по ФИО или названию группы;

открытие отдельной карточки студента;

отображение среднего балла.

Работа с оценками

просмотр оценок выбранного студента;

добавление оценки с указанием предмета и даты;

удаление оценки;

автоматический пересчёт среднего балла;

автоматическое удаление оценок при удалении студента.

Работа с группами

просмотр списка групп;

добавление новой группы;

удаление группы;

поиск группы по названию;

использование групп из базы данных при создании и редактировании студентов.

Работа с предметами

просмотр списка предметов;

добавление нового предмета;

удаление предмета;

поиск предмета по названию;

использование предметов из базы данных при добавлении оценки.

Хранение данных

Все данные хранятся локально в базе SQLite. Благодаря этому созданные студенты, оценки, группы и предметы сохраняются после закрытия приложения и доступны при следующем запуске.
